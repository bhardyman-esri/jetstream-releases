Added

  • Jetstream now requires a one-time team activation code on first launch,

entered once and remembered afterward. Since the release download is

hosted on a public GitHub Releases page (required for Sparkle

auto-updates to keep working), this activation gate is what actually

limits functional use of the app to teammates who've been given a code

by the admin — anyone without it only ever sees the activation prompt,

whether they're using the interactive UI, Shortcuts/App Intents, or

Watch Folders automation.

  • First-run onboarding tour (`Help > Jetstream Tour`), covering Workflow &

Deliverables, adding files, converting, Watch List automation, and where

Settings/Help live.

  • Settings > General > Export/Import Settings — save or load conversion

rules, the Workflow/Deliverable selection, and Watch List Rules as a JSON

file, so a configuration can be shared with a teammate or restored after

a reinstall.

  • Source, Plain Text, FWD HTML, and Outlook text panes now support native

macOS Find (`⌘F`), incremental matching, and Find Next/Previous—even in

read-only output.

  • Image review now uses a larger, resizable review surface with 260×170 image

previews, labeled source and destination URLs, visible Keep switches, a

full-size browser preview, selection counts, and Keep All/Drop All controls.

  • The blocking Marketo-token-plus-anchor review now offers **Skip and

Convert**, allowing the currently loaded source to proceed with a visible

warning through image-review reprocessing and deliverable adjustments. The

override resets when new input is loaded or the workspace is cleared.

  • The primary Convert action now sits in the sidebar directly below Open File,

and deliverable selectors use macOS toggle switches instead of checkboxes.

  • Image review now opens automatically after a conversion detects reviewable

images. Review Images is also available from the main toolbar, preserves the

full image inventory (including previously kept images), and reprocesses all

selected deliverables whenever the review closes.

  • Image review sheet: a "Review Images…" button appears whenever a Calcite

or Outlook conversion drops any images. It opens a modal review sheet

showing each dropped image's thumbnail, alt text, destination URL, and

source line, with a per-image "Keep" toggle. Applying your selections

reconverts the document with the kept images restored in their correct

position, rather than requiring manual copy/paste.

  • Settings > General > "Show app icon in Dock" — hide Jetstream from the

Dock and Cmd-Tab while keeping the menu bar item and windows fully usable,

applied immediately without restarting.

Fixed

  • Toolbar Watch List and Settings buttons now open the real Settings window

(Watch List Rules / Conversion Rules panes) instead of duplicate ad-hoc

popovers/sheets, matching the app-menu and menu-bar Settings behavior.

  • "Jetstream > Settings…" app-menu item now always opens on the General

pane instead of reopening on whatever pane (e.g. About) was last shown.

  • The line-number gutter no longer bleeds a vertical stripe up through the

workspace tab bar and pane headers above the editor. The text editor's

`NSScrollView` (which hosts the gutter ruler) did not clip its own layer

to its frame, so the ruler could paint outside its allotted area and

appear on top of the SwiftUI chrome stacked above it. Each editor's

scroll view now sets `wantsLayer = true` / `layer.masksToBounds = true`

so nothing inside it, including the gutter, can ever render outside its

own bounds. (Two earlier attempts in this cycle — removing a manual edge

stroke, then clipping the gutter's own fill rect — were both necessary

contributing fixes but not sufficient on their own; this scroll-view-level

clip is the fix that resolved it.)

  • Links containing both a Marketo token and a `#` anchor now stop conversion,

clear generated deliverables, and open the affected-link review immediately

instead of allowing an easy-to-miss warning.

  • The menu bar's "Open Jetstream…" command now recreates the main window

after it has been closed, instead of trying to foreground a nonexistent

`WindowGroup` window.

  • "Review Images…" now always presents its modal sheet, even when the

diagnostics drawer is collapsed.

  • "Check for Updates…" now shows only one "You're up to date" confirmation;

Jetstream no longer duplicates Sparkle's built-in result dialog.

  • Sparkle release notes are now published with the appcast so the updater can

display What's New without a download error.

  • Local development builds no longer start Sparkle without packaged updater

metadata or display a misleading updater failure.

  • Launch at Login now reports registration failures in Settings, refreshes the

switch from macOS's actual state, and clearly identifies development builds

where login-item registration is unavailable.

  • Redesigned Watch List settings as Watch Folders, with a prominent add action,

labeled controls, clearer folder paths, and accessible remove controls.

  • Removed the duplicate Jetstream app-menu Settings command and corrected

Settings navigation so the gear opens General while Watch Folders opens its

dedicated pane.

  • Calcite is now the default workflow on every launch, and workflow choices are

ordered alphabetically.

  • "Check for Updates…" now always gives explicit feedback: an alert confirms

when Jetstream is already up to date or reports the error if the check

fails, instead of silently doing nothing when Sparkle's own confirmation

didn't appear.

  • Calcite conversion now resolves Marketo `${...}` merge-tag tokens (e.g.

CTA button URLs) against their `<meta default="...">` declarations

instead of emitting the unresolved token, correctly excludes the logo

image via its tracking parameter instead of an incidental HTML-shape

match, restores platform-name labels ("Facebook", "LinkedIn", etc.) on

footer/social icon links, and now emits a warning (with line number) for

every other decorative image it drops instead of silently discarding it.

  • Calcite/Outlook plain text now moves the footer's social/community icon

row to appear before the legal/subscription boilerplate (with a divider

on both sides), matching the expected reading order instead of the raw

HTML source order.

  • Dropped-image warnings in the diagnostics drawer now include a "Copy

Text" button that copies the ready-to-paste caption/URL text for that

image, so you can quickly restore any image Jetstream drops that you

actually want to keep.
