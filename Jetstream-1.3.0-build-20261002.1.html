Added

  • Default toolbar order: Open, Paste, Review Images, Copy, Export, Watch Folders,

Flexible Space, Feedback, Report a Bug, Help, Settings.

  • Preview tab immediately after Source: a full-workspace WebKit HTML preview

with an icon switcher for Fit, Desktop, Tablet, Folding Phone and Mobile,

illustrative tablet/phone silhouettes, zoom, refresh, and default-on

remote images. Links and scripts are disabled; source and exports are unchanged.

Switching tabs preserves the window size and position; the email scrolls

inside the existing workspace. Preview stays disabled until source is loaded.

iPhone Duo has unfolded (626-point) and folded (466-point) widths with

a fold/unfold control. Illustrative devices preserve portrait screen proportions

and scale as a whole to fit the window without changing responsive viewport widths.

Device frames use matching screen/body corners, thinner phone bezels and

screen-positioned camera details rather than a stretched generic enclosure.

  • Link Report deliverable: tests every link and image in the source email

and lists each URL with its status, redirect target, link text and line

numbers. Bot-blocking sites (Facebook, LinkedIn, Cloudflare) are marked

Verify Manually instead of broken; Marketo-token domains are Not Tested;

`${variable}` links resolve from their defaults; redirects that drop

tracking parameters are flagged. Filter, search, recheck, copy and export

to CSV.

  • Link Inspector: double-click a Link Report row (or use Inspect) to see

the link's details, warnings and redirect chain, every line it appears

on, response time and last-checked time. Visit it, show it in the

Source tab, re-check it, or mark it as fixed.

  • Settings > Link Report: check images on/off, "do not check" rules

(URLs that contain / begin with / are on a domain), redirect handling

and tracking parameters, plus advanced options (user agent,

Accept-Language, timeout, request rate limit and simultaneous requests).

  • Lorem ipsum check: every conversion warns, with the line number, about

placeholder copy ("Lorem ipsum", "dolor sit amet", …) left in the source.

  • The Plain Text output can now be edited in place. Copy, Save and Export

use the edited text; an "Edited" badge and Revert Edits appear after

changes, and converting again replaces the edits.

  • Find button on the Source tab and Find / Replace buttons on the Plain

Text tab. Edit > Find adds Find… (⌘F), Find and Replace… (⌥⌘F), Find

Next/Previous (⌘G / ⇧⌘G) and Use Selection for Find (⌘E).

  • File > Open… (⌘O).

Changed

  • Deliverable tabs now appear only when their sidebar options are enabled.

Turning off the selected tab returns to Source without discarding its output.

The pill selector scrolls horizontally when space is limited.

  • The Source, Plain Text, FWD HTML, Outlook, and Link Report tabs are now a

sliding pill switcher. The blue selection glides between tabs, and it switches

instantly when Reduce Motion is on.

  • The toolbar now has a flexible space after Watch Folders by default, which

groups Feedback, Report a Bug, Help, and Settings on the right. A layout saved

with Customize Toolbar takes precedence.

Fixed

  • Conversion selects the generated deliverable rather than leaving Preview

active. Image review uses a stable snapshot, cannot open with an empty list,

and reprocesses the reviewed source once on dismissal without reopening itself.

  • Calcite plain text keeps body sections such as "Stay Connected" in place.

Footer social-icon reordering now starts at identified legal/subscription

copy instead of moving preceding body content into the footer.

  • Toolbar buttons have more room: icons sit clear of the title bar and

labels no longer crowd neighboring buttons.

  • The Source line-number gutter now counts real lines instead of wrapped

rows, so its numbers match warnings and the Link Report.
