Added

  • **Show Beta features** in Settings > General. When it's on, the sidebar

Workflow picker adds **Maps.com** (Beta) as a fourth workflow, laid out as a

2×2 grid with the sliding selection pill. Maps.com uses the Calcite rules

until its own rules are defined. Turning Beta off moves a Maps.com

selection back to Calcite.

  • **Convert** is now the first item in the sidebar. Clicking it (or

pressing ⌘R) before an email is loaded opens a file dialog, then converts

the chosen file.

It uses the same Liquid Glass style as the app's other buttons.

  • A soft-focus **jet stream** of particles, in the app icon's colors, whooshes

across the blue title bar each time you convert. Light and Dark mode each

have their own style, and the effect is skipped when Reduce Motion is on.

  • Link Report now requires the standard preference-center link,

`https://{{my.Preference Center}}?mkt_unsubscribe=1&mkt_tok=##MKT_TOK##`.

Unsubscribe or preference links with any other URL are reported as errors,

and an email with no preference-center link gets an error row.

  • Outlook conversion makes the preference-center **Update** link gray

(`#4d4d4d`) and underlined instead of blue. Turn it off in Settings >

Conversion Rules.

  • Outlook conversion keeps the Avenir web font and adds Verdana as its

fallback (`'Avenir Next World W05', Verdana, Arial, Helvetica, sans-serif`).

An Outlook-only style makes desktop Outlook, which can't load web fonts, use

Verdana instead of Times New Roman.

  • New Outlook rules from production review (each can be turned off in

Settings > Conversion Rules): remove the hidden preheader, replace empty

spacer paragraphs (`&nbsp;` or `<br>`, including empty Marketo editable

blocks) with one `<br />` after the paragraph above, use a 20px line

height for 14px body copy, remove the gray color from links, and style the

footer as 12px `#6a6a6a` text with an 18px line height.

  • Watch Folders can now **Open in Jetstream** instead of converting and

saving. New files load into the main window using the current Workflow,

Deliverables and Auto-convert settings. Choose it under **When a file

arrives** when adding or editing a Watch Folder. Existing Watch Folders keep

**Convert and Save**.

  • The home drop zone now fills the full height of the Source area. Dropping

a file crumples it into a paper ball, the inbox turns into a wire basket,

and the ball is tossed in like a basketball shot before the email loads.

Skipped when Reduce Motion is on.

  • Email Preview **Accessibility** inspector. Checks the email for common

WCAG 2.2 problems (missing or file-name alt text, links with no name or

vague text, missing `lang` and `<title>`, layout tables without

`role="presentation"`, missing or skipped headings, low inline-color

contrast, text under 12 px), grouped as errors, warnings, and suggestions

with line numbers. Selecting an issue outlines the element in the preview,

including inside CTSS Mail, and **Show in Source** jumps to the code.

**Reading Order** shows the email as a screen reader reads it.

  • Email Preview **Color vision** simulation: see the email and CTSS Mail as

readers with Deuteranopia, Protanopia, Tritanopia, or Achromatopsia would,

to check that meaning doesn't rely on color alone. Switching wipes the new

view down the screen (a quick fade with Reduce Motion).

  • Email Preview **Copy Image**: copies a picture of the entire email, top to

bottom, with the selected color vision simulation applied.

  • Accessibility **Read Aloud**: Reading Order can speak the email in screen

reader order, highlighting each item as it's read. Pick a voice, or use

**System Voice**, which follows Spoken Content (where a Siri voice can be

chosen). Marketo tokens are read as their preview values.

  • Settings › **Email Preview** pane with Email Client, Resolve Marketo tokens,

and Load remote images. These moved out of the Preview toolbar, and Load

remote images is now remembered.

  • CTSS Mail shows the sender's **BIMI logo** for Esri emails (Esri's

published, verified logo) in the message header and desktop inbox, the way

Gmail, Apple Mail, and Yahoo show verified senders. Other senders keep

initials. The logo is bundled; the preview makes no network request.

  • The CTSS Mail desktop sidebar rotates through all seven brand taglines,

cross-fading every 6 seconds (holds still with Reduce Motion).

  • VoiceOver announces status changes, such as conversion results, warnings,

and Link Report summaries.

  • Link Report **All Uses / Unique Links** view. All Uses lists every place a

link appears; Unique Links lists each link once. A new **Uses** column shows

how many times each link is used in the email. Copy, Copy Image, and Export

CSV follow the selected view.

  • Email Preview resolves common Marketo tokens (for example

`{{my.Current Year - Email}}` shows 2026, and tokens with `:default=` show

their default). Turn off **Resolve Tokens** to see them as written.

  • Email Preview shows the email inside **CTSS Mail**, an illustrative email

client, on Desktop, Tablet, iPhone Duo, and Mobile: status bar, message

navigation, subject and sender header, and Reply / Reply All / Forward.

Desktop is a three-pane mail window (folders, inbox, reading pane);

landscape Tablet and landscape open Duo add the inbox list; landscape

iPhone, portrait open Duo, and landscape closed Duo keep the tools in a

right-hand rail. The email has padding on both sides. The inbox row shows

the subject from the HTML title and the preheader as preview text. Turn off

**Email Client** to see the full device screen; Fit is unchanged. The

client's design tokens and layouts are documented in

`docs/ctss-mail/STYLE-GUIDE.md`.

  • Link Report: `mailto:` links are no longer requested. Valid email links show

an envelope icon with status **OK**; email links that carry UTM parameters

are flagged **Needs Change** (a warning) and list the parameters to remove.

  • iPhone Duo preview has a clear **Open | Closed** control, with fold marks on

both sides of the device.

  • The onboarding tour has a **Make It Yours** step to pick Light or Dark, an

app color, window transparency and blur, using the same controls as

Settings.

  • **Tint glass buttons** (on by default) lays a light wash of the app color

behind secondary Liquid Glass buttons; primary glass buttons are filled

with the app color.

  • Settings › General › **Appearance** picker (System, Light, Dark) applies to

every Jetstream window, and an **App color** swatch picker (Esri Blue by

default, plus Indigo, Purple, Pink, Red, Orange, Green and Teal) tints

buttons, selections and the title bar. The title bar now uses the same

color as buttons, so Esri Blue no longer shows two different blues.

  • Settings › General › **Appearance** › **Window transparency** slider, from

Opaque to 85% (never fully clear), and a **Background blur** slider from

Sharp (clear Liquid Glass) to Frosted (regular Liquid Glass). The desktop

shows through the sidebar and panels. Code editors and lists stay more opaque for legibility, the

email itself is never transparent, and Reduce Transparency keeps the window

opaque.

Defaults are 25% transparency and 75% blur, and **Reset Transparency &

Blur** returns to them.

Changed

  • Buttons use Liquid Glass while the window is translucent (prominent glass for main actions such as Convert, Activate, and Add Watch Folder; regular glass for Open File, Paste, Copy Image, Refresh, and Rotate) and solid bezels when the window is Opaque or Reduce Transparency is on. All bezeled buttons now share one style, `jetstreamButton()`.
  • Plain Text (Calcite): a linked headline no longer shows its URL when its section has a CTA button; the button carries the link. Linked list items and headlines in sections without a button keep their URLs.
  • Help rewritten in plain language, with a new Settings topic and screenshots of the main window, Preview, Accessibility, Review Images, link warnings, Link Report, and Settings (click a screenshot to view it full size).
  • The exact preference-center link

(`https://{{my.Preference Center}}?mkt_unsubscribe=1&mkt_tok=##MKT_TOK##`)

is now reported as **Auto Verified** instead of Not Tested.

  • After Convert, Jetstream opens the Preview tab automatically.
  • "HTML Preview" is now called **Email Preview**.
  • Settings slides down as a drawer inside the Jetstream window, and the

toolbar is disabled while it's open.

  • Removed the sidebar toggle from the main window.
  • Removed the large **Convert to …** button above the source code; use

**Convert** in the sidebar (or ⌘R).

Fixed

  • The Marketo token and # anchor warning now says "1 link contains"

instead of "1 link contain".

  • Outlook conversion now widens `style="width: 600px"` (and 552px) when the

declaration has no trailing semicolon. The Gmail fix (`min-width: 600px`)

is still removed.

  • Email Preview **Refresh** now matches the other toolbar buttons (icon and

label), and Rotate is sized like its neighbors. Refreshing spins the arrow,

dims the email, and fades the reloaded page back in so the reload is

visible.

  • The sidebar **Workflow** selector is centered, and its selection now slides

between Calcite, Globe, and Outlook (it switches instantly with Reduce

Motion). With four or more workflows it wraps into a two-column grid so

labels are never cut off.

  • Settings no longer casts a heavy shadow that blurred its text and icons.

The sidebar uses the standard macOS sidebar style and selection, and the

pane title reads as the pane name (for example "General").

  • VoiceOver: the Deliverables switches, Link Report search field, and

decorative icons now read correctly instead of "switch" or icon names.

  • iPad preview: the lower screen corners render cleanly with the email client.
  • Landscape iPhone preview no longer shows empty space on both sides of the

email client.

  • The toolbar can be customized again (right-click the toolbar or choose

**View › Customize Toolbar…**), and custom layouts, including spaces, are

kept after relaunch.

  • The Settings sidebar button stays in place when collapsing or expanding.
  • The iPhone camera no longer draws as a black leaf in landscape.
  • Restored the default flexible space between Watch Folders and Feedback.
