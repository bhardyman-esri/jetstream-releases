Added

  • Maps.com (Beta) joins the Workflow picker when Show Beta features is enabled in Settings > General. It appears as a fourth workflow in the 2×2 picker and uses Calcite rules for now; hiding beta features returns a Maps.com selection to Calcite.
  • Convert moves to the top of the sidebar. Before an email is loaded, click it or press ⌘R to choose a file and convert it.
  • Every conversion sends a soft-focus jet stream across the title bar, in the app icon's colors. Light and Dark mode get their own look; Reduce Motion keeps the forecast calm.
  • Link Report now checks for the standard preference-center URL, https://{{my.Preference Center}}?mkt_unsubscribe=1&mkt_tok=##MKT_TOK##. Other unsubscribe/preference URLs—and a missing preference-center link—are reported as errors.
  • Outlook can style the preference-center Update link gray (#4d4d4d) and underlined. You can turn this rule off in Settings > Conversion Rules.
  • Outlook keeps the Avenir web font and adds Verdana as its fallback ('Avenir Next World W05', Verdana, Arial, Helvetica, sans-serif). Desktop Outlook, which can't load web fonts, gets Verdana instead of Times New Roman.
  • New, individually switchable Outlook rules from production review: remove the hidden preheader; replace empty spacer paragraphs (&nbsp; or <br>, including empty Marketo blocks) with one <br /> after the paragraph above; set 14px body copy to 20px line height; remove gray link color; and style the footer as 12px #6a6a6a with an 18px line height.
  • Watch Folders can Open in Jetstream instead of converting and saving. New files use the current Workflow, Deliverables, and Auto-convert settings; existing folders keep Convert and Save.
  • The full-height home drop zone turns a dropped file into a paper ball and tosses it into a wire inbox basket. Reduce Motion skips the game.
  • Email Preview's Accessibility inspector checks common WCAG 2.2 issues: missing or filename alt text, unnamed or vague links, missing document language or title, layout tables without presentation semantics, heading gaps, low inline-color contrast, and text under 12px. Issues include severity and line numbers; selecting one highlights it in the preview, and Show in Source jumps to its code. Reading Order shows the screen-reader order.
  • Color vision simulation previews Deuteranopia, Protanopia, Tritanopia, and Achromatopsia in both the email and CTSS Mail, helping spot meaning that relies on color alone. Switching views gets a quick screen wipe (or fade with Reduce Motion).
  • Copy Image captures the whole email, top to bottom, with the selected color-vision simulation applied.
  • Accessibility Read Aloud speaks the email in screen-reader order and highlights each item. Choose a voice or System Voice (which follows Spoken Content settings); Marketo tokens use their preview values.
  • Settings > Email Preview now holds Email Client, Resolve Marketo tokens, and Load remote images; the last setting is remembered.
  • CTSS Mail shows Esri's published, verified BIMI logo in the message header and desktop inbox. The logo is bundled, so previewing it makes no network request; other senders keep their initials.
  • CTSS Mail's desktop sidebar rotates through all seven brand taglines every six seconds, unless Reduce Motion is on.
  • VoiceOver now announces status changes, including conversion results, warnings, and Link Report summaries.
  • Link Report's All Uses / Unique Links views show every placement or one row per URL. The Uses column counts placements; Copy, Copy Image, and CSV export follow the selected view.
  • Email Preview resolves common Marketo tokens, including :default= values. Turn off Resolve Tokens to see the original tokens.
  • CTSS Mail adds a simulated email client to Desktop, Tablet, iPhone Duo, and Mobile previews. It includes mail navigation, sender and subject details, and reply actions. Desktop uses three panes; landscape Tablet and open Duo also show the inbox, while other layouts use a right-hand rail. The inbox uses the HTML title and preheader, and Email Client can be turned off to show the full device screen. The design tokens and layouts are in docs/ctss-mail/STYLE-GUIDE.md.
  • Link Report no longer requests mailto: links. Valid addresses show OK; email links with UTM parameters are flagged Needs Change with the parameters to remove.
  • iPhone Duo now has a clear Open | Closed control and fold marks on both sides.
  • The onboarding tour adds Make It Yours, covering appearance, app color, window transparency, and blur.
  • Tint glass buttons adds a light app-color wash behind secondary Liquid Glass buttons; primary glass buttons use a solid app-color fill.
  • Settings > General adds System, Light, and Dark appearance modes plus eight app colors: Esri Blue, Indigo, Purple, Pink, Red, Orange, Green, and Teal. Buttons, selections, and the title bar now share one color—no more competing blues.
  • Appearance settings also add window transparency (Opaque to 85%) and background blur (Sharp to Frosted). Editors and lists stay more opaque, the email stays solid, and Reduce Transparency keeps the window opaque. Defaults are 25% transparency and 75% blur; Reset Transparency & Blur restores them.

Changed

  • Buttons use Liquid Glass in translucent windows and solid bezels when the window is opaque or Reduce Transparency is on. Primary actions get prominent glass; other actions use regular glass. All bezeled buttons share jetstreamButton().
  • Calcite Plain Text keeps linked headlines tidy when a section has a CTA button: the button carries the URL. Other linked headlines and list items retain theirs.
  • Help is rewritten in plain language, adds a Settings topic, and includes screenshots of the main window, Preview, Accessibility, Review Images, link warnings, Link Report, and Settings. Click any screenshot to enlarge it.
  • The exact preference-center URL (https://{{my.Preference Center}}?mkt_unsubscribe=1&mkt_tok=##MKT_TOK##) is now Auto Verified instead of Not Tested.
  • Convert now opens the Preview tab automatically. "HTML Preview" is now Email Preview.
  • Settings now slides down as a drawer in the main window; the toolbar is disabled while it is open.
  • Removed the main-window sidebar toggle and the large Convert to … button above the source. Convert is in the sidebar (or press ⌘R).

Fixed

  • The Marketo token and # anchor warning now says "1 link contains" (not "1 link contain").
  • Outlook now widens style="width: 600px" and 552px declarations even when they have no trailing semicolon. Gmail's min-width: 600px fix is still removed.
  • Email Preview's Refresh now matches the toolbar (icon and label), and Rotate is sized to match its neighbors. Refreshing spins the arrow, dims the email, then fades it back in.
  • The sidebar's Workflow selector is centered and slides between Calcite, Globe, and Outlook (instantly with Reduce Motion). Four or more workflows wrap into a two-column grid so labels stay visible.
  • Settings no longer casts a heavy shadow over text and icons. Its sidebar now uses the standard macOS style, and pane titles show their names.
  • VoiceOver now gives the Deliverables switches, Link Report search field, and decorative icons sensible descriptions.
  • iPad preview corners now render cleanly with the email client; landscape iPhone preview no longer leaves empty space beside it.
  • Toolbar customization works again, and custom layouts (including spaces) survive relaunch. The Settings button also stays put when the sidebar collapses or expands.
  • The iPhone camera no longer looks like a black leaf in landscape, and the default flexible space between Watch Folders and Feedback is back.
