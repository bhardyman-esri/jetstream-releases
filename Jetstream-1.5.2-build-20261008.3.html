Recovery for a crashing 1.5.1 install: download the 1.5.2 DMG, drag Jetstream into Applications, and choose Replace. Existing preferences and configuration are preserved; automatic updates resume after launch.

Changed

  • Export keeps it simple: Plain Text, FWD HTML, and Outlook HTML. Removed the Plain Text as Markdown and HTML options.

Added

  • Export All as Package saves all three deliverables in one ZIP.
  • Native macOS WidgetKit support adds Small and Medium Jetstream status widgets with current conversion status and shortcuts to choose an email or review. Requires App Group capability group.com.esri.jetstream for both app IDs.

Fixed

  • Packaged apps explicitly load their SwiftPM resource bundle from Contents/Resources, preventing a toolchain-dependent crash at launch.
  • About's GitHub link now opens the public distribution repository.
